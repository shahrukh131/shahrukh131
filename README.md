### 👨‍💻 About

I build fast, maintainable web platforms with **React, Next.js and TypeScript**, and own the backend too with **NestJS and PostgreSQL**. I lead a small frontend team and care about performance you can measure.

### 🏆 Recent wins

| | |
|---|---|
| ⚡ **26× faster API response** | Cut a key page's main API call from 2.66 s → ~100 ms and requests per page from ~16 → 7 |
| 🧠 **Smarter data layer** | Moved data fetching to TanStack Query + IndexedDB caching — no more duplicate requests or race conditions |
| 🔒 **Security hardening** | Shipped CSP, upload validation and XSS sanitization, backed by 39 Jest / RTL tests |
| 🏗️ **Multi-tenant SaaS** | NestJS + schema-per-tenant PostgreSQL, BullMQ, Socket.IO, Meilisearch |
